# v0.5.1 检查记录

本地制作环境：Linux / GCC / Bash。没有 macOS SDK、AppKit 或 Apple clang。

已执行：

- 十种布局的几何计算：113,277 条断言通过，含比例、间距、多显示器坐标和分区互不重叠。
- 自动归位策略：固定分区保留、已知窗口优先、未固定空位优先、全固定不分配、四格切两格及切换取消通过；穷举 1–4 格占用与固定掩码。
- 拖动规则测试、27 项安装策略及失败回滚模拟、中文提示在 CURRENT/C/C.utf8 环境下检查通过。
- 核心 C 模块采用 -std=c11 -O2 -Wall -Wextra -Werror -pedantic 编译。
- Shell 语法、窗口控制流和版本信息在仓库中检查。

GitHub Actions 使用 macOS ARM64 runner 编译 Objective-C 原生 App，并运行 C 测试、签名校验与 DMG 校验。对应 run 见仓库 Actions 页面；不要把本地 Linux 的测试当成真实 Mac 操作验收。

仍需在用户 Mac 上验证：辅助功能授权与升级、新窗口焦点、按窗口固定和解除固定、最小化恢复、低分辨率界面、多个 Spaces、外接显示器及不同应用兼容性。详细清单见 MAC_ACCEPTANCE.md。
