# v0.8.0 检查记录

本版围绕用户报告的“点击窗口左右切换”及常用方案要求重构。

## 已验证

- 113281 个几何断言：十种布局、比例、间距、多显示器坐标。
- 拖动几何：标题栏与内容区、边框、坐标滞后兜底、用户三格坐标下的左右/上下落点。
- 52500 个分配判定：已知分区稳定、未知窗口均衡填空、1000 窗口叠放无替换、拖动期间布局不得使提交失效。
- 配置：版本 1～3 迁移入口、旧固定与临时占位保留、逐字节备份、版本 4 重启、保存方案深复制、重命名身份稳定、同应用多窗匹配、同名不猜、损坏配置不覆盖。

- macOS 原生编译、App 包、临时签名完整性、27 个安装/回滚场景、非交互环境不重置辅助功能权限、PKG 与 DMG 生成及校验。
- macOS 离屏渲染两页 980×610 界面，检查布局按钮、常用方案、叠放菜单、设置项，没有滚动容器。离屏预览使用示例方案，不接管 CI 桌面窗口。

上述基础重构已在开发分支 Actions 36702545932 通过；关闭/重开窗口和读取超时保留身份的扩展测试在 Actions 36703595066 通过。最终发布仍运行同一完整流程。

## 验证边界

协调器测试替换系统窗口读写适配器，验证真正控制器的事件状态，不是 macOS 26 真实窗口操作。真实鼠标命中、各应用最小尺寸、系统堆叠/焦点和辅助功能授权，需要按 MAC_ACCEPTANCE.md 在用户 Mac 上复核。
