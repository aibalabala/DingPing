# v0.8.0 实机验收

对象：Mac mini M4，macOS 26。模拟系统适配器测试不能替代本清单。

安装前退出定屏，双击 PKG；安装后核对版本 0.8.0、构建 20、路径 `/Applications/定屏.app`，辅助功能已授权。

| 操作 | 应观察到 |
|---|---|
| 开两个 Chrome、Code、访达、终端，点左半右上下 | 五个窗口都获得归属，多出的叠放；三格均有窗口 |
| 连续点击两个 Chrome 30 次 | 每个 Chrome 保持自己的格，不左右切换 |
| 将右上窗口拖到左格 | 只移动被拖窗口，左格原窗口留在下面，右上露出下层窗口或变空 |
| 将左格窗口拖到右下 | 与横向同一规则，位置保存 |
| 松手后立即打开菜单/诊断 | 提交完成，复制诊断显示新的归属，菜单不取消拖动 |
| 拖动中按快捷键切换布局 | 先提交拖动，再执行排队的布局；切回可看到已记忆的新位置 |
| 修改 Chrome 标签/终端标题，再反复点击 | 活窗口的身份与分区不变 |
| 最小化栈顶 | 显示同格下一可用窗口，其他格不迁移；最小化窗记录保留 |
| 恢复最小化窗口 | 回原格并置前 |
| 关闭栈顶 | 显示同格下层；关闭窗记忆保留 |
| 打开新普通窗口 | 默认在当前操作格叠放；关闭该设置后空格优先/数量最少 |
| 保存“编程”，拖动窗口，再切另一布局和切回“编程” | 编程恢复新位置，另一个布局保留自己的位置 |
| 另存“写作”，修改“写作”中的窗口位置 | 编程的记忆保持原样 |
| 重命名/删除方案 | 重命名不丢记录；删除进入自由模式，窗口保持打开 |
| 退出重启 | 保留最后方案和模式；能唯一识别的窗口恢复位置；最小化仍最小化 |
| 两个 Chrome 窗口同名后重启 | 不凭应用名猜旧固定目标；作为新窗口分配，旧记忆保留 |
| 进入自由模式，拖动并点击窗口 | 不再自动归位 |
| 开启禁止标题栏拖动，再尝试内容区拖拽 | 标题栏移动被阻止，文本选择/内容拖拽继续 |
| 切其他桌面/断开显示器/休眠后返回 | 不移动其他桌面的窗口；目标显示器可用后维护恢复 |
| 检查布局页、更多设置页 | 内容在固定长方形内完整显示，无滚动条和重叠按钮 |

发现问题时记录动作先后顺序，并复制“权限与窗口诊断”；至少包含拖动诊断、方案记录、分区坐标和最近事件。
