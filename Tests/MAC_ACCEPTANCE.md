# v0.5.1 Mac 验收（待执行）

以下项目尚未在此制作环境执行。纯 C 测试不覆盖 AppKit、辅助功能权限、实际焦点或应用兼容性。

建议窗口：浏览器两个不同窗口、访达、备忘录，再用一个聊天软件作为新窗口。先确认当前 App 路径与辅助功能授权。

| 场景 | 预期 |
| --- | --- |
| 全新安装 | 默认自由模式；激活/拖动窗口均不自动调整 |
| 旧版升级 | 方案保留；旧 App 被替换，/Applications 中经验证的定屏副本移到废纸篓；更换签名后进入授权修复引导 |
| 旧授权开关仍开，但新版未授权 | 用 DMG 修复工具核对版本，按 ID 尝试清理旧记录，手动移除残留旧条目并从个人 Applications 重新添加；不改动其他应用 |
| 已安装相同签名构建 | 不反复重装、不重置已成功的授权；若仍有经验证的旧副本则移到废纸篓 |
| 首次点击两栏 | 使用目标屏已有窗口填未设置空位，排列并前置；成功后收起设置 |
| 同一应用两窗口 | 各占一格，切换文档不会当成同一个窗口 |
| 激活新窗口，存在空格 | 填编号最小的空格 |
| 两格已满，最后使用右格后激活聊天 | 聊天进入右格，左格不变，右格旧窗口不关闭 |
| 固定左格浏览器，激活多个新窗口 | 左格一直留给浏览器，新窗口只进入未固定分区 |
| 固定全部当前分区，再激活新窗口 | 新窗口保持原位，界面提示没有可用分区 |
| 关闭已固定窗口，激活其他窗口 | 固定位置仍保留；重新打开原窗口后再尝试唯一匹配 |
| 四格固定第三格，切到两栏再返回 | 固定选择保留；两栏期间不把该窗口塞入其他格 |
| 菜单固定当前窗口并取消 | 固定位置立即生效，取消后恢复自动接纳 |
| 手动交换和另存方案 | 固定窗口不参与交换；每个方案分别保存固定状态 |
| 自由模式与重新启用 | 自由模式可随意摆放，重新启用后固定窗口回原格 |
| 再激活被替换的文档 | 回原来的右格 |
| 同应用内点另一窗口 / Command + 反引号 | 焦点变化也触发归位，不仅监听应用切换 |
| 单击预览指定替换分区 | 黑框改变；新窗口在无空位时进入所选分区 |
| 再点当前布局 | 重新排列并前置，保持自动模式 |
| 最小化 / Command + H 隐藏 | 显式布局切换尝试恢复；布局中可用窗口前置 |
| 关闭一窗口 / 同标题两窗口 | 跳过缺失/歧义项，不自动启动或随便替换 |
| 快速点两栏、三栏、自由模式 | 最后为自由模式；没有旧任务迟到抢焦点 |
| 恢复动画中点击/输入 | 中止剩余前置动作；后续操作由用户控制 |
| 切换后再激活其他软件 | 当前软件归位后可正常输入；后台不轮流激活布局窗口 |
| 自由模式 | 没有自动归位、回位或标题栏拦截，保留当前坐标 |
| 自由模式重启 | 仍为自由模式 |
| 自动模式重启 | 记住模式，后台不把整组窗口抢到前台 |
| 保存 A/B 两套组合并切换 | 各自的窗口与形状独立，当前一组被排列并前置 |
| 另存 / 改名 / 删除方案 | 另存改名不抢焦点；删除进入自由模式，不关闭窗口 |
| 四格变两格再激活原第三格 | 进入有效分区，无越界或重复占格 |
| 第二显示器 / 拔掉目标屏 | 其他屏新窗口不自动拉来；目标断开时暂停，可无权限进入自由模式 |
| Spaces 与全屏 | 不强制退出全屏或跨桌面搬运，当前不可见窗口跳过 |
| 打开保存对话框、弹窗、菜单 | 不把这些界面缩放进分区 |
| 最小尺寸大于分区 | 提示并暂停该窗口的固定，其他窗口可用 |
| 阻止拖动 | 标题栏拦截，内容区选字/拖文件正常；切自由模式立即放行 |
| 恢复分屏前位置 | 先进入自由模式，再恢复本次运行记录 |
| 撤销权限后点布局 | 不自动反复弹系统设置；自由模式入口仍可用 |
| 低分辨率屏幕 | 横向窗口按屏幕缩放，主页与更多设置页均无滚动条，底栏可见 |

安装验证：运行「检查安装环境.command」，应依次通过三组 C 测试、真实提示语回归、原生编译、Info.plist 和本地签名检查。记录 App 版本 0.5.1、构建 8，以及目标应用名称、窗口场景和复现顺序。
