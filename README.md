# 定屏 DingPing

macOS 菜单栏分屏工具，使用辅助功能调整普通窗口的位置和尺寸。

当前版本：**v0.8.0（构建 20）**。本版重构窗口管理：每个窗口记住自己在每份布局中的分区，每格允许多个窗口叠放。点击只置前，手动拖动修改分区；关闭或最小化后显示下面的窗口。

## 操作

1. 点击任一布局，当前目标显示器、当前桌面的普通可调整窗口全部获得分区归属；多出的窗口叠放。
2. 拖动窗口标题栏到另一格：移入并置顶，该格已有窗口保留在下面。位置自动保存，默认不交换窗口。
3. 点击窗口或通过分区列表选择窗口：在自己的分区置前，分区归属保持稳定。
4. 点「保存为常用方案」，输入“编程”“写作”等名称；顶部直接点击方案名称即可恢复形状、比例、间距和窗口位置。前三份显示为按钮，全部方案在下拉菜单中。
5. 「管理当前方案」提供另存、重命名、删除。常用方案与内置布局分别记忆，切换不共用窗口占位。
6. 「更多设置」可选择新窗口去向、恢复最小化窗口、禁止标题栏拖动和目标显示器。自由模式停止自动归位，保留记忆。

内置左右两栏、上下两栏、三栏、三行、四格、左右主窗加上下、左半右上下、左上下右半、上主窗加左右、左主窗加右侧三行等常用布局。界面采用 980×610 的横向双页面，没有滚动条。

「固定位置」保留旧固定记录的标记；所有窗口本来就会记住归属，手动拖动可以更新固定位置。固定不代表永久置顶，新窗口可以在同一格叠放，下面的窗口及其记录都保留。

## 安装与升级

要求 macOS 13 或更新版本。Apple Silicon 用户在 [Releases](https://github.com/aibalabala/DingPing/releases) 下载 `DingPing-v0.8.0-macOS-arm64.pkg`，先退出定屏，再双击安装。也可打开 DMG，再双击其中的「双击安装定屏.pkg」。安装位置为 `/Applications/定屏.app`。

图形安装不要求 Command Line Tools。安装器验证和备份旧 App；新程序核验成功后，将个人 Applications 中已验证的旧副本移到废纸篓。布局配置保留。首次运行在「系统设置 → 隐私与安全性 → 辅助功能」授权当前路径。

本版将配置升级为版本 4，先原样备份到 `layouts-before-0.8.0.json`，再迁移每份旧方案的固定记录和最近窗口。旧版本已经丢失的记录无法自动恢复。未知或损坏配置保留原文件，本版停止覆盖保存。

App 使用临时签名，没有 Developer ID 公证。更换构建后，macOS 可能需要重新授权当前 App；更多设置中的「修复旧版授权」和 DMG「高级安装」提供引导。稳定免重复授权需要同一 Developer ID 签名。诊断路径出现 `/AppTranslocation/` 时，请通过 PKG 安装后从 `/Applications/定屏.app` 启动。

从源码安装：完整解压仓库，退出定屏，双击 `双击安装.command`；需要 Apple Command Line Tools，安装到 `~/Applications/定屏.app`。只读验证可运行 `检查安装环境.command` 或 `检查已安装版本.command`。

## 状态与识别

只自动接纳目标显示器当前桌面的普通可调整窗口。全屏、弹窗和其他桌面不参与自动移动。最小化窗口保留归属，默认不因布局切换而恢复；可在更多设置中开启恢复。

运行期间用真实窗口身份区分同一应用的多个窗口，窗口改标题不改变归属。重启后优先使用唯一文档或唯一标题匹配；同名窗口或标题全部变化时按新窗口接纳，避免猜错。关闭窗口的记录保留，可靠识别到重新打开的窗口时恢复原分区。位置或尺寸被应用限制时，暂停该窗的重复调整，点击当前方案重试。

程序不联网、不截图、不记录键盘内容。配置保存窗口的应用标识、标题、可用文档标识、分区和叠放顺序；「权限与窗口诊断」可复制实际位置和最近事件。

## 架构与验证

| 文件 | 职责 |
|---|---|
| `WorkspaceStore.m` | 版本 4 配置、迁移备份、独立方案、窗口记录与保守匹配 |
| `WindowCoordinator.m` | 窗口身份、全部窗口分配、各格叠放、最小化/关闭、执行移动 |
| `WorkspacePolicy.c` | 拖动优先级、布局交易、过期回调失效、首次分配规则 |
| `WindowAccess.m` | macOS 辅助功能读写、鼠标下窗口识别 |
| `main.m` | 两页界面、常用方案入口、菜单、快捷键、拖放输入 |
| `DragPolicy.c` / `DragGuard.m` | 拖动几何判定、可选标题栏拦截 |

GitHub Actions 在 Apple Silicon macOS runner 上运行几何、事件策略、配置迁移、真实协调器（模拟系统适配器）和安装回滚测试，编译 App、渲染界面并校验 PKG/DMG。模拟窗口测试验证程序的状态变化，不等于 macOS 26 上的真实鼠标拖放已验证。实机清单见 [Tests/MAC_ACCEPTANCE.md](Tests/MAC_ACCEPTANCE.md)，使用细节见 [使用说明](使用说明.md)。
